## Rich text tags

- **Color** - Specify text color
	- "0-255"/"#00-#ff": Specify *Alpha* value
	- "0-255,0-255/#0000-#ffff": Specify *RGB* and *Alpha* values
	- "0-255,0-255,0-255/#000000-#ffffff": Specify *RGB* values
	- "0-255,0-255,0-255,0-255/#00000000-#ffffffff" Specify *RGBA* values
- **B** - Quickhand for bold text
- **I** - Quickhand for italic text
- **BI** - Quickhand for bold-italic text
- **Style** - Set the font style
	- "Weight": Set a specific *style* from the *current font*
	- "Weight style": Set a specific *style* from the *current font*
- **Size** - Specify text size
	- "0-Inf px/em" - Specify current *size* of text in pixels or ems
- **Stroke**: Set stroke state
	- "False-True": Enable or disable *stroke* for the text
- **SColor** - Set stroke color
	- "0-255"/"#00-#ff": Specify *Alpha* value
	- "0-255,0-255/#0000-#ffff": Specify *RGB* and *Alpha* values
	- "#000000-#ffffff": Specify *RGB* values
	- "#00000000-#ffffffff" Specify *RGBA* values
- **SWeight** - Set stroke weight
	- "0.0-Inf": Specify the *weight* of the stroke
- **Disable** - Disable processing of rich text
- **Br** - Break the line

<br>

> NOTE: All tags are lowercase
<br>
> NOTE: All units are in *em*s
